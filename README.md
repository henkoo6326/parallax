# PARALLAX

현장 수행과 상황 보고, 인계 검토가 같은 사건 상태를 공유하는 폴더블 웹 프로토타입입니다.

## 실행

Python 3가 설치된 환경에서 프로젝트 폴더를 열고 실행합니다.

```sh
python3 launch.py
```

사용 가능한 로컬 포트로 서버를 시작하고 브라우저를 엽니다. macOS에서는 start.command를 실행해도 됩니다. 별도 패키지 설치나 빌드는 필요하지 않습니다. ES 모듈을 사용하므로 HTTP 서버로 실행하세요.

## 현재 기능

- 펼친 화면의 두 작업 패널과 접힌 화면 사이에서 작성 내용과 사건 상태를 유지합니다.
- 현장 수행, 상황 보고, 인계 검토와 자료 확인·변경 사유·인계 수락 흐름을 제공합니다.
- 기본 지도는 MapLibre와 OpenFreeMap의 실제 지도를 사용합니다. Apple MapKit 토큰은 필요하지 않습니다.
- 드론 보기에서는 생성 이미지 위에 팀원·차량·출입구·주차장·CCTV·합류 위치를 매핑합니다.
- 지도 요소 선택 시 상세 시트가 열리며 연결 업무·담당·근거와 확인 결과를 볼 수 있습니다.
- 메모, 보고서 초안, 기록과 확인 결과는 브라우저 로컬 저장소에 저장됩니다.
- 화이트·다크 모드, 영상 샘플 재생, 장면 캡처, AR 글래스 장비 화면과 시야 예시를 제공합니다.

## 시연 범위

기본 지도의 배경만 실제 지리 정보입니다. 사건 건물 및 팀원·차량·시설 위치는 시연용 가상 배치이며 실제 사건 위치나 실시간 위치가 아닙니다. 드론 이미지는 생성 이미지로, 실제 항공사진이나 측량 자료가 아닙니다. 층수·내부 구조·카메라 설치 위치도 검증되지 않았습니다.

AR 연결, 영상 스트리밍·녹화, 음성 인식, AI 제안, 다른 팀과의 전송은 시뮬레이션입니다. 카메라와 마이크에 접근하지 않습니다. 샘플 영상 재생은 정지 이미지 기반 타이머로 동작합니다.

지도 SDK와 타일을 불러오려면 인터넷 연결이 필요합니다. 작성한 메모·보고서 등 브라우저의 로컬 데이터는 GitHub 소스에 포함되지 않습니다.

## 파일 구성

- index.html, app/: 현재 폴더블 앱
- assets/: 이미지·로고·폰트
- docs/: 설계 및 지도 적용 기록. 이전 방식의 문서는 당시 검토 기록입니다.
- tests/: 상태 전환과 지도 모델 검증
- research/: 참고 자료
- capture.html, app/capture-*: 이전 스크린샷 내보내기용 보관 파일

Apple MapKit 관련 모듈은 이전 검토용으로 보관되어 있습니다. 현재 기본 지도에는 사용하지 않습니다.

## 검증

```sh
node --test tests/*.test.mjs
node --check app/main.mjs
```
