# PARALLAX

현장 수행과 인계 검토가 같은 사건 상태를 공유하는 폴더블 앱 디자인 프로토타입.

## 실행

이 폴더에서 `python3 -m http.server 8765 --bind 127.0.0.1` 실행 후 http://127.0.0.1:8765 를 엽니다.

별도 패키지 설치나 빌드가 필요하지 않습니다. ES 모듈을 사용하므로 HTTP로 실행합니다. 외부 웹폰트가 없어도 시스템 한글 글꼴로 표시됩니다.

## 체험

1. 지도에서 공동현관 CCTV를 선택하면 오른쪽 영상 패널이 열립니다.
2. 상단의 영상 + 보고서 조합으로 자료를 보며 보고 내용을 입력합니다.
3. 접힌 화면으로 바꿨다가 다시 펼치거나 새로고침해도 보고 내용이 유지됩니다.
4. 소통에서 오프라인 상태 시험 → 메시지 전송 → 연결 복구 → 다시 전송을 체험합니다.
5. 인계 검토에서 자료 확인 → 확인 체크 → 인계 수락 → 수락 확정 → AR로 이어받기를 진행합니다.
6. 각 패널 상단 선택 메뉴로 작업을 독립적으로 변경합니다. 같은 편집 도구를 선택하면 패널을 교환합니다.

## 범위

실제 동작: 로컬 상태 저장, 임무 체크, 편집, 기록 추가, 메시지 대기열, 재전송, 인계 상태 전환, 폴드 전환, 두 패널 작업, 브라우저 음성 합성(지원하는 환경).

시뮬레이션: AR 연결, 영상 스트리밍/녹화, 음성 인식, AI 초안/캡처 제안, 다른 경찰·지휘실과의 전송. 카메라와 마이크에 접근하지 않으며 외부 수신자에게 보내지 않습니다. 영상 프레임과 지도는 생성 이미지입니다. 층 선택은 구역 정보를 바꾸며 실제 3D 지형이나 실내 도면을 생성하지 않습니다.

실서비스에는 기관 인증·역할 권한, 사건 API, 실시간 통신, 실제 지도/실내 위치, 미디어 서버, AR 기기 SDK, 암호화 저장과 재전송 보장, 감사 이력 및 현장 사용자 검증이 필요합니다.
