# 통제실 디자인과 업무 흐름의 폴더블 적용

2026-09-21 1차 반영

## 1. 공통 디자인
- 시스템 글꼴, 정상 자간, 본문 16px과 여유 있는 행간으로 가독성 개선.
- 화이트·쿨그레이 바탕과 블루 조작 색상. 경고와 완료는 의미에 맞는 별도 색상 유지.
- 주요 조작 영역 최소 44px. 콘텐츠는 불투명하게, 내비게이션과 지도 도구에만 반투명 재질 적용.
- 네이티브 SwiftUI Liquid Glass가 아니라 웹 CSS로 구현한 디자인 원칙 적용이다.

## 2. 구역별 업무
- 지도에서 인계 건물 또는 실내 선택 구역을 열면 재확인 요청, 미확인 사유, 작성자, 영상 시점을 표시.
- 확인 결과를 입력하고 재확인 필요 / 확인 중 / 완료 상태로 저장.
- 결과는 이 브라우저의 기록과 인계 검토 화면에 함께 표시되며 실제 다른 단말로 전송하지 않는다.

## 3. 변경 이유
- 주요 변경 이력에 변경 전후 내용, 작성자, 시각, 사유와 연결 장면을 표시.
- 변경 읽음 표시와 현장 업무 완료를 분리.
- 현재 이력은 고정된 시연 자료이며 과거 시점 재생 기능은 포함하지 않는다.

## 4. 지도
- 실제 OpenStreetMap 주변 지도 위에 가상 작전 지점을 표시.
- CCTV 예상 시야 토글 제공. 가상 방향·각도의 도형이며 건물 가림이나 실제 사각지대를 계산하지 않는다.
- 기존 실내도와 드론뷰 전환 유지.

## 검증
- 상태 전이 테스트 19개 통과.
- 브라우저에서 구역 상세, 결과 입력 폼, 변경 이력, CCTV 시야 토글, 접힌 화면 렌더링 확인.

## 색상 정정
원본 Theme.swift 기본 프리셋에 맞춰 강조색 #2446F0, 긴급 #E9392F, 추정 #F5C744, 확인 #5FCB5B로 정정. 이전 #245AC1은 자체 조정값이었다. 경고 칩의 어두운 글자와 반투명 배경은 원본 CertChip 규칙을 따른다. 사용자 지정 KeyStore 저장값은 프로젝트 소스에 포함되지 않으므로 기본 프리셋 기준이다. 이후 검토는 1차 글자·색·컨트롤부터 진행한다.


## ④ 지도 시야각·상황 이력 보완 — 2026-09-21

- CCTV 위치를 꼭짓점으로 방향 270°, 시야각 70°, 거리 90m의 부채꼴을 표시한다. 수치는 시연용이며 장애물, 실제 촬영 범위, 사각지대를 계산하지 않는다. 시야 정보에서 설정과 연결 영상을 확인하고 해당 카메라 위치로 이동할 수 있다.
- 카메라 레이어가 꺼지면 예상 시야도 숨긴다. 지도 배율 16 미만에서는 현장·합류 지점만 남기고 카메라·팀·확인 요청의 세부 핀을 숨긴다. 확대하면 선택된 레이어에 맞춰 다시 표시한다.
- 주요 변경 이력은 초기 시연 항목, 작성한 변경 요청, 저장한 현장 확인 결과를 표시한다. 새 결과를 저장해도 이전 결과의 내용·업무 상태·기록자·시각·연결 영상 시점이 남는다. 기록은 결과 항목을 먼저 최신 저장 순으로, 요청·지휘 항목은 별도로 역순 표시하며 모든 항목의 시각을 표시한다.
- 이력 선택 → 사유·내용 검토 → 연결 영상 시점 / 관련 구역 지도 → 기록 검토 종료. 검토 중에는 상단에 기록 시각과 제목을 표시한다. 현재 임무·완료 상태·초안을 과거로 되돌리지 않으며 긴급 알림 버튼도 유지한다.
- 이전 저장본의 현장 결과는 현재 남아 있는 마지막 결과를 이력에 연결한다. 보존되지 않았던 과거 수정본을 새로 만들어 내지 않는다.
- 임무 화면의 변경 사항 진입점도 같은 이력으로 연결한다. 지도 하단에서는 선택 구역의 남은 업무 수와 업무 열기를 제공한다.

검증: `node --test tests/*.test.mjs` 28개 통과. 새 이력과 이전 저장본 복원, 임무 상태 보존, 구역 이동, 시야 좌표·레이어 연동 검증. 브라우저에서 이력 선택 → 구역 지도 → CCTV 정보 → 지도 축소에 따른 세부 핀 숨김 → 연결 영상 0:51 이동 및 접힌 화면 확인.

①~④의 합의된 웹 프로토타입 범위를 반영했다. 실제 기기 통신·영상 스트리밍, 장애물을 고려한 시야 계산, 사건 전체를 과거로 재생하는 기능은 포함하지 않는다.
