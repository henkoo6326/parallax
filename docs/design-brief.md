# PARALLAX — 현장을 이어가다

## 레퍼런스 분석

- 사용자 첨부 1: 거의 검은 상단, 그린 영역의 겹쳐진 둥근 패널, 원형 도구 버튼, 기록과 첨부 자료를 연결하는 타임라인. 이를 임무 카드, 인계 카드, 기록 목록에 적용.
- 사용자 첨부 2: 딥 틸 입체 공간, 녹색으로 강조된 선택 대상, 공간에 부착된 라벨, 작은 지도 도구. 이를 지도 기본 화면과 CCTV 선택에 적용.
- https://dribbble.com/shots/27705170-Lockheed-SaaS-Drone-Defense-Mobile-App : 페이지에 제시된 #031013, #1F3B43 계열의 낮은 명도 공간 색상 참고.
- https://dribbble.com/shots/27502611-Lockheed-SaaS-Drone-Defense-Mobile-App : 페이지에 제시된 검정·그린 계열 색상과 여러 센서 정보를 한 화면에서 다루는 설명 참고. 페이지의 사업 성과 주장은 제품 검증 근거로 사용하지 않음.
- CityBldr 링크는 열람하지 못했고 MP4는 가져오기에 실패함. 해당 영상의 움직임을 관찰했다고 가정하지 않음.

## 시각 방향

잉크 블랙/딥 틸 공간과 라임색 행동 버튼, 에메랄드 선택 건물. 위험도와 주의는 별도 라벨/아이콘으로 구분. 지도 위에서만 반투명 패널을 사용하고 본문은 불투명하게 유지. Manrope + Noto Sans KR, 시스템 글꼴 대체. 지도는 가상 건물 입체 이미지이며 선택 구역의 색은 안전 판정이 아님.

## 앱 구조

현장 수행과 인계 검토는 같은 사건을 공유하는 업무 모드다. 사건 ID, 기록, 보고서, 연결 상태는 공통 상태로 유지된다. 순서대로 다음을 누르는 구조를 없애고 임무, 지도, 영상, 기록, 소통으로 직접 이동한다. 인계/AR 관리/보고서는 관련 메뉴 및 펼친 패널 선택 메뉴에서 접근한다.

접힘: 단일 업무 화면, 하단 탐색, 음성 행동과 AR 상태. 펼침: 두 작업 패널을 독립적으로 선택. 빠른 조합은 지도+임무, 영상+보고서, 지도+인계. 입력과 사건 상태는 localStorage에 저장한다. 편집 중 다른 작업으로 이동해도 보고 내용은 남는다.

## 서비스처럼 느껴지는 부분

- 버튼 의미와 결과 일치: 완료는 체크 대상 확인을 요구하고 임무 상태/기록을 갱신.
- 자료 연결: 지도 CCTV → 해당 영상 → 장면 캡처 → 기록 → 보고서.
- 저장과 전송 구분: 초안 저장, 최종 검토, 오프라인 대기, 재전송을 별도 상태로 표현.
- 인계: 내용 열람과 수락 분리, 확인 체크와 확정, AR 연결 확인 후 후속 팀 임무로 전환.
- 음성: 입력 내용 확인 → 기록 저장 또는 보고서 검토, 지원 브라우저에서는 음성 합성 브리핑.
- 시스템 상태: AR 연결 끊김, 오프라인, 녹화 대기/기록 중, 전송 대기를 사용자 행동에 연결.

## 남아 있는 제품 개발

지금 산출물은 프런트엔드 인터랙션 프로토타입이다. 실제 장비/사용자 간 통신과 AI 추론은 구현하지 않았다. 실서비스화 시 사건·구역·자료·메시지·인계 패키지에 고유 ID/버전을 부여하고 서버의 수신 확인 및 수락 이벤트를 연결해야 한다. 저장 시 암호화와 역할별 열람 권한, 재시도 중복 방지, 업데이트 충돌, 자료 보존 정책을 구현한다. 실제 폴더블/AR와 현장 사용자를 대상으로 장갑 조작, 주야간 가독성, 통신 장애 복구를 검증한다.

## 이미지

두 자산은 built-in image_gen으로 새로 생성했다. 참조 이미지를 복제하지 않고, 공간의 색감과 계층을 별도 가상 현장으로 재구성했다.

- assets/scene-map.png: 딥 틸 주거 지역과 중앙 에메랄드 건물. 지도 및 드론 예시 화면에 사용.
- assets/scene-camera.png: 가상의 공동현관 CCTV 시점. 영상·북마크·장면 제안에 사용. 실제 사건 기록 아님.

## 검증 기록

상태 테스트: 보고서/카메라 선택의 접힘 유지, 오프라인 보고 대기와 재전송 중복 방지, 인계 수락 조건과 이어받기, 임무 완료 조건, 빈 보고서 차단, 동일 편집 도구의 패널 교환, 오프라인 인계 재전송.

브라우저: CCTV 클릭 → 영상 패널, 보고서 입력 → 접기/펼치기/새로고침 → 내용 보존, 보고서 검토/전송, 오프라인 메시지 대기/연결 복구/재전송, 인계 확인 및 수락 후 임무 전환. 430px 폭에서 문서 가로 넘침 없음 확인.

최종 생성 프롬프트 전문: [image-prompts.md](image-prompts.md).

## 화이트 테마 추가

사용자 요청으로 화이트/다크 전환과 테마 저장을 추가했다. 흰 패널, 회백색 바탕, 세이지 임무 카드, 짙은 그린 버튼, 밝은 3D 지도로 화이트 테마를 구성했다. 폴드 전환/모드 전환/새로고침에도 테마와 업무 내용을 보존한다.

원 CityBldr 링크는 열람되지 않았다. 검색에서 찾은 동일 제작자의 별도 [CityBldr 게시물](https://dribbble.com/shots/27262351-CityBldr-Mobile-App-Real-Estate-Investment-Platform)과 [상세 이미지](https://cdn.dribbble.com/userupload/47329700/file/d479478fe11f73711e4897050c3d5efa.png?resize=752x&vertical=center)에서 흰 상단, 밝은 회색 건물, 반투명 회색 필터 UI를 직접 확인하고 반영했다.

assets/scene-map-light.png는 기존 생성 지도의 구도/건물을 보존하고 밝은 화이트·그레이 건물 및 민트색 선택 대상으로 바꾼 built-in image_gen 편집본이다.
