# UI 정렬·컨트롤 점검 — 2026-09-21

사용자가 첨부한 메시지 전송 버튼을 출발점으로 임무, 기본·실내·드론 지도, 영상, 기록, 보고서, 소통, 인계, 글래스 화면과 팝업을 점검했다.

## 원인과 수정

- 전송 버튼은 입력칸에 맞춰 높이만 늘어나 44×52px이 되었고, SVG가 인라인 기준선에 배치되어 위로 치우쳤다. 48px 공통 높이와 정사각형 버튼, grid 중앙 정렬로 수정했다. 브라우저 측정 결과 48×48px, SVG 중심 오차 x/y 모두 0px이다.
- themes/refinement의 이전 남색이 전송 버튼에 남아 있었다. 공통 강조색 #2446F0를 사용한다.
- 화면 컨트롤에만 적용되었던 크기 규칙을 팝업까지 공통으로 적용했다. 입력·주요 버튼은 48px, 보조 버튼·필터·패널 선택·재생 조작의 터치 높이는 최소 44px이다. 버튼 행은 동일한 flex 기준으로 정렬한다.
- 글래스 조작점은 공통 블루와 44px 터치 영역을 사용하되, 실제 원형 표시는 28px로 유지한다.
- 지도 헤더의 독립된 절대 위치 요소 때문에 좁은 화면에서 메모·탭·시야 안내·확대 버튼이 겹쳤다. 기본·실내·드론뷰의 메모와 패널 선택을 공통 헤더 안에 넣고, 기본 지도의 시야 안내도 같은 레이아웃 흐름에 배치했다. 실내·드론 층 선택은 가로 행으로 정리했다.
- 지도 탭의 한글이 한 글자씩 줄바꿈되던 현상을 수정했다. 좁은 화면에서 네 개의 탭이 가로로 맞는다.
- 팝업보다 위에 떠 있던 폴드 버튼을 팝업 뒤로 배치했다. 700px 이하 실제 브라우저 폭에서는 폴드 버튼이 기기 아래 별도 영역을 차지하여 하단 메뉴·입력칸을 가리지 않는다. 큰 화면에서는 기존 고정 버튼을 유지한다.
- 다크 테마의 선택 메뉴·링크·수신 표시 대비를 보정했다. 주요 버튼과 선택 메뉴의 배경은 공통 블루, 텍스트는 흰색이다. 어두운 면 위의 보조 액션은 밝은 블루를 사용한다.

공통 규칙은 app/controls.css에 모으고 화면 레이아웃 다음에 로드한다.

- 펼친 화면: 1024px에서 일곱 업무 메뉴의 버튼 높이, 텍스트 잘림, 패널 가로 넘침 검사. 모두 문제 없음.
