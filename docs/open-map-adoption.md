# OpenFreeMap 작전 지도 연결 — 2026-09-21

현재 지도는 MapLibre GL JS 5.6.0 + OpenFreeMap Liberty 기반이다. 가입·Apple 토큰 없이 로딩한다. 시험 화면에서 확인한 2D 건물 스타일과 한국어 우선 라벨을 적용했다. 필수 지도 출처 표시는 유지한다.

## 위치 의미

- 화곡역 인근 지도에서 건물 Polygon 하나를 직접 선택하여 `open-map-model.mjs`에 저장했다. 윤곽 출처는 OpenFreeMap / OpenStreetMap이며 측량 정확도나 최신성을 보증하지 않는다.
- 이 위치는 실제 사건 위치가 아니다. “시연 건물 · 가상 배치”를 지도 핀·제목·업무 카드에 표시한다.
- 2층과 3층·옥상은 같은 건물의 가상 업무 그룹이다. 실제 층수나 내부 구조를 확인한 것이 아니다.
- 실제 건물 윤곽과 명시적인 시연 위치를 구분해 올린다. 팀·차량·시설 좌표는 가상 배치이며 실제 위치 수신으로 표시하지 않는다.
- 팀명은 현재 담당·인수 상태에 따라 상세 카드에 표시한다. 현재 위치 정보로 해석하지 않는다.
- 출입구·주차장·CCTV의 실제 좌표는 위치 미확정 목록에 둔다. 시연 표식과 연결 영상을 제공하지만 지도 시야각은 추정하지 않는다.
- 업무 완료는 해당 층의 요청에만 적용된다. 건물 윤곽은 완료 여부와 관계없이 파란색으로 유지하며 건물 전체 완료로 표현하지 않는다.

## 동작과 실패 처리

휠·트랙패드·터치 확대/축소, 드래그 이동은 MapLibre 기본 동작을 사용한다. 화면 위치는 기존 Apple/SVG 좌표와 분리한 openMapViewport로 저장한다. 지도 다운로드가 실패해도 업무 목록을 사용할 수 있고 재시도 버튼을 표시한다. 외부 지도 서버 연결은 필요하다.

Apple 연결 코드는 apple-live-map.mjs에 참고용으로 보존하며 현재 앱에서는 로드하지 않는다.

## 팀·차량·시설 시연 확장 (후속 요청 반영)

기존의 '지도에 위치 미확정 항목을 올리지 않는다'는 방식에서, 실제 좌표는 미확정으로 유지하되 **명시적인 가상 배치**를 체험할 수 있는 시연 모드로 확장했다. 현장 2팀, 증원 1팀, 순찰차 21호, 출입구, 주차장, CCTV, 합류 지점을 제공한다. 모든 객체의 출처는 simulation이며 실제 위치 수신으로 표시하지 않는다. 지도 표식과 대상 목록은 같은 선택 상태를 사용하고, 상세 카드에서 연결 업무 또는 영상 자료를 연다.

90초 이동 시연은 일시정지 상태로 시작한다. 재생·정지·시간 탐색·초기화, 팀·차량·시설 레이어 숨김, 선택 대상 따라가기를 지원한다. 차량 선형은 렌더링된 도로에서 추출했고 팀 선형은 인접 도로를 참고했다. 실제 이동 기록이나 통행 가능 경로는 아니다. 끝에서 정지하며 이동·도착이 업무 완료나 인수 확정을 변경하지 않는다. 드래그·확대 조작 시 따라가기를 해제한다. GPS나 차량 관제 피드는 아직 연결하지 않았다.

하단 AR·배터리·동기화·음성 바를 제거하고, 해당 높이 52px(접힌 화면 58px)를 작업 영역에 추가했다. 글래스와 음성 보고는 기존 메뉴에서 접근할 수 있다.
